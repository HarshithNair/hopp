# Reference-inspired UI refresh

The interface follows the user's supplied phone-screen reference through a scenic network card, saturated blue/mint/coral/yellow shortcuts, rounded conversation bubbles, a glowing interactive radar, blue wristband styling, and a red SOS confirmation panel. Peers remain explicitly simulated; no fake live health, delivery, weather, or nearby counts were introduced.

Original landscape asset: `public/images/hopp-valley.webp` (1200×800, approximately 193 KB). Created with the built-in image generation tool, then optimized to WebP for local serving and offline precaching.

Generation prompt:

> Use case: stylized-concept. Asset type: scenic background for HOPP mobile emergency communication app's interactive network card. Create an original polished illustrated alpine valley at sunset: layered blue and lavender distant mountain peaks, warm peach and gold horizon, dark emerald pine trees framing both sides, a winding turquoise river and green forest valley below. Premium modern adventure-app illustration with painterly geometric shapes, refined depth, soft warm light, vibrant but sophisticated. Wide landscape 3:2 composition. Upper left and central lower valley have calm uncluttered areas to overlay white UI headings and glowing network nodes in code. No text, no UI, no logos, no people, no map pins, no paths or connection lines. Nature scenery only.

The radar uses interactive HTML/SVG over this artwork. Reduced-motion preferences disable animations. Preparedness progress derives from actual shell readiness, profile name, and emergency contact fields; it is a setup checklist, not a safety score.
